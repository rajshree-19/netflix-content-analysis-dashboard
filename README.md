# Netflix Content Analysis Dashboard

## Project Overview

An interactive Netflix content analysis dashboard developed using Microsoft Power BI and Excel to explore and visualize Netflix content data.

## Tools Used

- Microsoft Power BI
- Microsoft Excel

## Dashboard Analysis

The dashboard provides an interactive view of Netflix content, allowing users to explore:

- Content distribution
- Movies and TV shows
- Genres
- Ratings
- Release trends
- Other key content insights

Interactive visuals and filters were used to make the analysis easier to explore and interpret.

## Key Skills Demonstrated

- Data preparation
- Data cleaning
- Data visualization
- Dashboard development
- Interactive reporting
- Power BI
- Microsoft Excel

## Project Outcome

The project provided hands-on experience in transforming raw content data into an interactive dashboard and presenting data-driven insights through visualizations.

## Project File

The Power BI `.pbix` file is included in this repository and can be opened using Microsoft Power BI Desktop.
